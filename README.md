# SafeFall AI — Agentic Fall Detection & Context-Aware Emergency Response

> **Hackathon MVP Prototype**  
> *Autonomous Elder-Care Fall Detection, Verification, and Multi-Channel Simulated Emergency Dispatch Orchestrator.*

---

## ⚠️ Safety, Medical & Prototype Disclaimer

**THIS SOFTWARE IS A PROTOTYPE FOR DEMONSTRATION AND RESEARCH PURPOSES ONLY.**  
- SafeFall AI is **NOT** a certified medical device (FDA / CE certified) and must **NOT** be used as a substitute for professional healthcare, emergency medical services (EMS), or in-person caregiving.
- It does **NOT** diagnose medical conditions, determine unconsciousness, detect gas or smoke, or establish physiological health.
- Pose-based computer vision signals are treated strictly as **potential fall indicators**, not conclusive evidence of a fall.
- All emergency notifications (SMS, WhatsApp, Voice Call) generated by this system are **EXPLICITLY SIMULATED** within the interface; no unsolicited calls or messages are dispatched to public telecom networks or 911 PSAPs.
- SafeFall AI does **NOT** operate physical door locks or access gates.

## Key Features

1. **Mission-Control Dashboard**: Clean, responsive healthcare-oriented dashboard with real-time operational status, active zone monitoring, and top-line KPI metrics.
2. **Zero-Camera Simulated Fall Trigger**: Reliable, one-click `⚡ SIMULATE FALL INCIDENT` button allowing rapid scenario testing (slippery bathroom tile, stairs, kitchen trip, bedside transfer) without requiring any physical camera.
3. **Optional Webcam & Synthetic Sensor Stream**:
   - Live pose estimation via OpenCV and MediaPipe (when available).
   - Graceful fallback: If OpenCV/MediaPipe or webcam hardware is missing, the dashboard automatically runs with a synthetic sensor telemetry generator.
4. **Interactive Verification Countdown**:
   - Configurable countdown timer (5s – 30s) providing resident agency.
   - **"✅ I'M OK"**: Aborts escalation, logs a self-resolved false alarm.
   - **"🚨 NEED HELP"**: Immediately escalates incident.
   - **Auto-Timeout**: If resident is unresponsive when the timer hits zero, the agent automatically flags a Critical Emergency.
5. **Context-Aware Agentic Triage Engine**:
   - Assesses room-specific environmental hazards (e.g., hard tile & moisture in bathrooms vs. soft carpet in living rooms).
   - Generates contextual reasoning, severity classifications (`Low`, `High`, `Critical`), and prioritized action plans.
6. **Simulated Multi-Channel Emergency Dispatch**:
   - **Simulated SMS**: Standardized text alert with zone and response plan.
   - **Simulated WhatsApp**: Rich-formatted card with emergency status, zone pin, and demo intercom link.
   - **Simulated Voice Call**: Text-to-speech audio transcript of automated phone dispatch.
7. **Persistent SQLite Database (`safefall.db`)**:
   - Preserves incident logs across app reboots.
   - Filterable table with CSV export.
8. **Interactive Analytics & Trends**:
   - Spatial room breakdown and severity distribution charts.
9. **Demo Controls & Subsystem Diagnostics**:
   - `🌱 Seed Demo Data` button for immediate presentation evaluation.
   - `🗑️ Reset All Data` button to clean logs for fresh testing.

## Technology Stack

- **Dashboard**: [Streamlit](https://streamlit.io/)
- **Programming Language**: Python 3.12 / 3.9+
- **Persistence**: SQLite 3 (native zero-config database)
- **Computer Vision**: OpenCV (`cv2`) & MediaPipe (optional with graceful fallback)
- **Visualization**: Plotly & Altair / Streamlit native charts
- **Zero Paid APIs**: Runs 100% locally with no required API keys or subscriptions.

## Installation & Windows Execution

### Option 1: One-Click Launch (Recommended)
Double-click `run.bat` in Windows Explorer, or execute in command line:
```cmd
run.bat
```

### Option 2: Manual Terminal Execution (PowerShell)

1. Open PowerShell in `d:\SAFEFALL AI`:
```powershell
# Create virtual environment (if not already created)
python3.12 -m venv .venv

# Activate virtual environment
.\.venv\Scripts\Activate.ps1

# Install dependencies
pip install -r requirements.txt

# Launch SafeFall AI Streamlit Dashboard
streamlit run app.py
```

2. Open your web browser to:
```text
http://localhost:8501
```

## Verification & Testing Guide

| Step | Action | Expected Result |
|---|---|---|
| **1. Startup** | Run `streamlit run app.py` | Dashboard loads showing `🟢 PASSIVE SCANNING` and disclaimer. |
| **2. Demo Data** | Click `🌱 Seed Demo Data` in the sidebar | 3 realistic past incidents appear in the history table and charts. |
| **3. Fall Simulation** | Click `⚡ SIMULATE FALL INCIDENT` | Screen switches to `🟡 VERIFYING EVENT` with a countdown progress bar. |
| **4. "I'm OK" Test** | Click `✅ I'M OK` during countdown | Escalation cancelled, recorded as `Resolved - False Alarm` in SQLite. |
| **5. "Need Help" Test** | Trigger simulation, click `🚨 NEED HELP` | Immediately creates `Escalated - Help Requested` and displays simulated SMS/WhatsApp/Voice dispatches. |
| **6. Timeout Test** | Trigger simulation, let countdown expire (0s) | Automatically escalates to `Critical` with simulated emergency dispatches. |
| **7. Persistence Test** | Refresh browser or restart app | All incidents remain stored and visible in the SQLite history table. |
| **8. CSV Export** | Go to `📜 SQLite Incident History` tab, click `📥 Export` | Downloads `safefall_incidents_*.csv`. |
